阿里云告警需按资源类型分级，并与 Runbook 联动。

## 告警分级

| 级别 | 场景 | 响应 |
|------|------|------|
| P0 | RDS 主库不可写、全站 SLB 后端不可用 | 5 分钟 |
| P1 | 单 AZ ECS 全 down、Redis 内存 >90% | 15 分钟 |
| P2 | 磁盘 >75%、CPU 持续高 | 1 小时 |
| P3 | 证书 30 天过期、RI 到期 | 工作日 |

## 核心告警清单

| 资源 | 指标 | 阈值 |
|------|------|------|
| ECS | CPUUtilization | ≥80% 5min |
| ECS | DiskUsage | ≥85% |
| RDS | ConnectionUsage | ≥80% |
| RDS | DiskUsage | ≥85% |
| Redis | MemoryUsage | ≥80% |
| SLB | UnhealthyServerCount | ≥1 |
| OSS | 可用性 | <99.9% |
| ACK | 节点 NotReady | ≥1 |

## 值班速查

### RDS 不可连接

```
1. 控制台 → RDS → 监控 → 连接数/CPU
2. 白名单是否变更
3. 主备切换事件
4. 应用连接池是否打满
5. 工单或提额
```

### SLB 502/504

```
1. 后端健康检查
2. ECS/容器是否存活
3. 安全组
4. 最近发布
```

### ECS 批量失联

```
1. 同 AZ 是否网络故障（阿里云公告）
2. 安全组/NACL 变更
3. 系统盘满
4. 批量 OOM
```

### 费用突增（FinOps P2）

```
1. 费用中心 → 产品明细
2. 是否流量/快照/新实例
3. 标签异常资源
```

## 事件订阅

```
消息中心 → 系统维护、故障公告
→ 自动同步到 on-call 频道
```

## On-Call 原则

1. 先恢复（扩容、切流、回滚）
2. 云平台故障查 [阿里云状态页]
3. 变更单关联告警时间线
4. 48h Postmortem

告警按 **env=prod** 优先，dev/staging 降级别。
