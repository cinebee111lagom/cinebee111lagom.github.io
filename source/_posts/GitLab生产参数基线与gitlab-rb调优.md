`gitlab.rb` 是 Omnibus 唯一配置源，生产需 **基线化 + Git 管理**。

## 安全基线

```ruby
gitlab_rails['gitlab_signup_enabled'] = false
gitlab_rails['password_authentication_enabled_for_web'] = true
gitlab_rails['require_two_factor_authentication'] = true
gitlab_rails['two_factor_grace_period'] = 168  # 小时

nginx['ssl_protocols'] = "TLSv1.2 TLSv1.3"
nginx['redirect_http_to_https'] = true
```

## 性能基线

```ruby
# Puma workers（约 CPU 核数）
puma['worker_processes'] = 4
puma['min_threads'] = 4
puma['max_threads'] = 4

# Sidekiq 并发
sidekiq['max_concurrency'] = 20

# Git 超时
gitlab_rails['git_timeout'] = 600
gitaly['configuration'] = {
  timeout: { default: '5m' }
}
```

## CI/CD 基线

```ruby
gitlab_rails['artifacts_enabled'] = true
gitlab_rails['artifacts_expire_in'] = "30 days"
gitlab_rails['ci_jwt_signing_key'] = '<auto-generated>'

registry['enable'] = true
registry_nginx['listen_port'] = 5050
```

## 日志

```ruby
logging['logrotate_frequency'] = "daily"
logging['logrotate_size'] = nil
logging['logrotate_rotate'] = 30
```

## 变更流程

```bash
vim /etc/gitlab/gitlab.rb
gitlab-ctl reconfigure
gitlab-ctl restart   # 仅当 reconfigure 提示需要
```

**所有变更**记录变更单，staging 先验证。

## 反模式

- 手工改 `/var/opt/gitlab` 下文件
- reconfigure 无监控 Sidekiq 队列积压
- 生产开启 signup

基线文件存 **内部 Git**，Ansible/Chef 下发。
