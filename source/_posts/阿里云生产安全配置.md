阿里云生产安全覆盖身份、网络、数据、审计四层。

## 身份安全

| 项 | 配置 |
|----|------|
| RAM MFA | 管理员强制 |
| 无 AK 泄露 | 密钥轮转、AccessKey 审计 |
| RBAC | 最小权限策略 |
| SSO | 企业 IdP 对接 |

## 网络安全

```
WAF（Web 攻击防护）
DDoS 高防（大流量）
安全组 + NACL 最小放通
VPC 私网隔离
堡垒机（运维 SSH/RDP 审计）
```

## 数据安全

| 产品 | 措施 |
|------|------|
| RDS/OSS | KMS 加密、SSL |
| 传输 | HTTPS/TLS 1.2+ |
| 备份 | 加密存储 |

## 云安全中心

- 漏洞扫描、基线检查
- 异常登录告警
- 合规检查（等保）

## WAF 规则

- OWASP 核心规则集
- CC 防护
- Bot 管理
- 自定义 IP 黑白名单

## ActionTrail + 配置审计

```
所有 API 调用 → SLS
Config 规则：检测公网 RDS、开放 22 端口等
```

## 等保/合规

- 日志保留 ≥ 180 天
- 三权分立（可选）
- 定期渗透测试

## Checklist

- [ ] 无公网 RDS/Redis
- [ ] OSS 禁止公共读
- [ ] WAF 保护公网 Web
- [ ] 堡垒机运维
- [ ] KMS 加密关键数据
- [ ] 安全中心高危漏洞清零

安全与 **RAM 治理、VPC 基线** 联动，非单点配置。
