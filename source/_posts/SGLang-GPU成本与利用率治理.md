GPU 是最大成本项。SRE 要让钱变成 **有效 token**，而不是空转卡。

## 成本视角指标

| 指标 | 含义 |
|------|------|
| GPU 利用率 | 是否空转 |
| 有效 token/s / 卡 | 产出 |
| 队列等待 | 是否该扩 |
| 命中率 | 同等 QPS 下成本红利 |
| 闲置卡时 | 可回收预算 |

## 治理动作

| 现象 | 动作 |
|------|------|
| 低利用 + 低排队 | 缩容/合并池 |
| 高利用 + 高排队 | 扩容或限流分级 |
| 命中率低 | 优化路由/prompt 稳定性 |
| 实验池长期占卡 | 定时回收、抢占 |
| 小模型过度 TP | 改副本策略 |

## 核算建议

- 按模型池周报：卡时、token、单位成本  
- 把网关 429 与拒绝量纳入「未服务需求」  
- 大模型与小模型分账，避免平均掩盖浪费  

## 反模式

- 只看利用率不看排队（可能该扩）  
- 为微吞吐长期占满顶级卡  
- 无主的「临时实验」卡永远临时  

**成本优化不能牺牲已承诺的核心 SLA；先保 SLO，再挤水分。**
