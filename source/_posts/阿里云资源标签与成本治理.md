标签与成本治理是云 SRE 的**持续职责**，避免资源 sprawl 和账单失控。

## 标签策略

```
必填：env, app, team, owner, cost-center
可选：project, version

通过标签策略（Tag Policy）强制
未打标资源 → 告警 + 禁止创建（SCP）
```

## 成本分析

```
费用中心 → 分产品 / 分标签 / 分账号
月度报告：
  - Top 10 应用成本
  - 环比异常 >20% 分析
  - 闲置资源清单
```

## 优化手段

| 手段 | 适用 |
|------|------|
| 包年包月 / RI | 稳定 ECS/RDS |
| 节省计划 SP | 计算通用折扣 |
| 弹性伸缩 | 波动负载 |
| Spot 抢占式 | 可中断任务 |
| 降规格 | CPU/内存长期 <30% |
| OSS 生命周期 | 冷数据转 IA/归档 |
| 释放闲置 | 无流量 SLB、 unattached 云盘 |

## 闲置资源巡检

```bash
# 定期脚本/云助手
- 7 天 CPU <5% 的 ECS
- 未挂载云盘
- 空 Bucket
- 0 连接 RDS 测试实例
```

## 预算与告警

```
费用预算：prod 账号月度上限
告警阈值：80%、100%、120%
```

## Checklist

- [ ] 标签覆盖率 > 95%
- [ ] 月度 FinOps review
- [ ] RI/SP 利用率 > 80%
- [ ] 闲置资源工单闭环

**SRE 不是只保可用，也要保成本可控**。
