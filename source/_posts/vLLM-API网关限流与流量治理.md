网关是推理平台的 **安全带**：鉴权、限流、路由、观测。

## 网关职责

```
TLS 终止 → 鉴权 → 配额 → 路由到模型池 → 超时/重试策略 → 访问日志
```

可用 Nginx、Envoy、Kong、APISIX、自研 Gateway。

## 限流维度

| 维度 | 示例 |
|------|------|
| 按 API Key | 60 RPM |
| 按租户 | 1M TPM/天 |
| 按模型 | 大模型更严 |
| 并发 | 每 key ≤ 10 in-flight |

超限：`429` + 明确错误体。

## 超时与重试

| 项 | 建议 |
|----|------|
| 连接超时 | 短 |
| 读超时 | 覆盖长生成（如 300s） |
| 重试 | 仅幂等/网络错误；流式慎重试 |
| 熔断 | 后端错误率高时快速失败 |

## 路由

```
model=chat-7b  → svc-chat
model=coder    → svc-coder
default        → 拒绝或默认小模型
```

## 观测

网关侧导出：QPS、429、5xx、按 key 的 TPM，与 vLLM 指标对照。

## 反模式

- 无网关直连 vLLM
- 无限流导致一个租户打挂整池
- 对流式请求错误重试造成重复计费/重复生成

网关配置 **GitOps 化**，变更需评审。
