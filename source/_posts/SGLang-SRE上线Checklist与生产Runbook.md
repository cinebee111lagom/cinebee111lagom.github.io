## 上线 Checklist

### 架构

- [ ] 模型/卡型/TP/副本策略已文档化
- [ ] 小模型多副本或大模型恢复路径明确
- [ ] 网关鉴权 + 限流就绪
- [ ] 高前缀场景的路由/亲和策略已评估

### 配置

- [ ] 启动参数基线入库（Git）
- [ ] 上下文长度 / 并发上限经压测
- [ ] API Key / Secret 非明文仓库

### 模型

- [ ] 制品 checksum / digest 校验
- [ ] 生产 OFFLINE，不临时下载
- [ ] 回滚版本路径可用

### 监控

- [ ] /metrics 可刮取
- [ ] TTFT/队列/缓存命中/GPU 面板
- [ ] P0/P1 告警 + Runbook 链接

### 验收

- [ ] 黄金用例通过（含结构化输出若启用）
- [ ] 流式正常
- [ ] 压测达 SLO 90% 以上

## 日常 Runbook

| 频率 | 动作 |
|------|------|
| 每日 | 看 P0/P1、排队、GPU OOM、命中率异常 |
| 每周 | 利用率与成本、慢请求 Top |
| 每月 | 密钥轮换、镜像 CVE |
| 每季 | 故障演练、基线重压测 |

## 应急

| 事件 | 动作 |
|------|------|
| 服务 Down | 重启/回滚镜像；切备池 |
| OOM 风暴 | 降并发 → 降上下文 → 扩容 |
| TTFT 飙升 | 查队列、长 prompt、缓存冷启动；扩容或 429 |
| 命中率骤降 | 查发布/LB 策略是否打散亲和 |
| 错误内容投诉 | 转算法；临时关相关模型路由 |

## 反模式

- Checklist 未完成接全量
- 应急只重启不留根因
