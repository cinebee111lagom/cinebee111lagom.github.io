推理服务常能触达 **内部知识与用户输入**，必须按生产 API 治理。

## 控制面

| 项 | 建议 |
|----|------|
| 鉴权 | 网关 API Key / mTLS / OIDC |
| 网络 | 仅内网或零信任入口 |
| 管理口 | metrics/调试口不暴露公网 |
| Secret | K8s Secret / 保险箱，禁明文 Git |
| 镜像 | 私有仓库 + 扫描 |

## 数据面

- 日志脱敏：prompt / 输出默认不全量落盘  
- 多租户隔离：按模型池与密钥分权  
- 出网：生产建议 OFFLINE，禁随意拉模型  

## 配置基线

- 关闭不必要的调试端点  
- 最小权限 SA  
- NetworkPolicy：仅网关与 Prometheus 可访问  

## 审计

| 内容 | 用途 |
|------|------|
| 谁调用了哪个 model | 追责与成本 |
| 配置变更 | 变更审计 |
| 镜像 digest | 供应链追溯 |

## 反模式

- SGLang 端口直接打到公网  
- 团队共用一个永久 Key  
- 把用户对话明文进无权限控制的日志平台  

**安全与可用性一样，是上线门禁，不是事后补丁。**
