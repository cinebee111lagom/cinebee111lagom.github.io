**弹性伸缩 ESS** 与 **ACK HPA** 是应对流量波动的核心能力。

## ESS（ECS 弹性伸缩）

```
伸缩组
├── 最小/最大/期望实例数
├── 多 AZ vSwitch
├── 启动模板（镜像、规格、UserData）
├── 缩放规则（定时/报警/预测）
└── 关联 SLB/ALB 服务器组
```

## 报警任务示例

```
指标：CPUUtilization 平均值
条件：>= 70%，持续 3 分钟 → 加 2 台
条件：<= 30%，持续 10 分钟 → 减 1 台
冷却：300s
```

## 容量规划

| 维度 | 方法 |
|------|------|
| 基线 | 日常峰值 CPU < 60% |
| 大促 | 预估 QPS × 压测单实例能力 |
| 预留 | min 实例 ≥ 2 AZ 各 1 |
| 上限 | max 防成本失控 |

## ACK HPA

```yaml
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: api-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: api
  minReplicas: 3
  maxReplicas: 20
  metrics:
    - type: Resource
      resource:
        name: cpu
        target:
          type: Utilization
          averageUtilization: 70
```

## 预测伸缩

ESS 支持基于历史模式的**预测伸缩**（大促前预热）。

## 成本平衡

| 策略 | 说明 |
|------|------|
| 按量 + 预留券 | 基线预留，峰值按量 |
| Spot 实例 | 批处理、可中断 |
| 定时伸缩 | 夜间缩容 |

## Checklist

- [ ] min ≥ 2（多 AZ）
- [ ] max 有预算 cap
- [ ] 扩容后验证 SLB 健康
- [ ] 缩容 graceful（preStop）
- [ ] 大促前压测 + 预测规则

弹性是**成本与体验的平衡**，非无限扩容。
