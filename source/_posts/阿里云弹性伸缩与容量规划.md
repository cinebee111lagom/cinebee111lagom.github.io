弹性伸缩（ESS/HPA）与容量规划平衡**成本与稳定性**。

## ESS（ECS 弹性伸缩）

```
伸缩组：min=2, max=20, desired=4
多 AZ：均衡分布
触发：
  - CPU >= 70% 5min → +2
  - CPU <= 30% 10min → -1
冷却：300s
```

```
启动配置/launch template：
  镜像、规格、安全组、用户数据
  自动加入 SLB 后端
```

## ACK HPA/VPA

```yaml
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
spec:
  minReplicas: 3
  maxReplicas: 30
  metrics:
    - type: Resource
      resource:
        name: cpu
        target:
          type: Utilization
          averageUtilization: 70
```

```
Cluster Autoscaler：节点池自动扩
```

## RDS/Redis 垂直扩容

```
监控 ConnectionUsage、MemoryUsage
低峰窗口升配
部分支持在线扩容
```

## 容量规划流程

```
1. 压测得 baseline QPS/CPU
2. 峰值 × 1.5 余量
3. min 保证 HA（≥2）
4. max 设成本上限
5. 大促前手动调 max + CDN 预热
```

## 定时伸缩

```
夜间：min=2（降本）
白天：min=4
大促：cron 提前扩容
```

## 监控

| 指标 | 说明 |
|------|------|
| 伸缩活动失败 | P1 |
| 达到 max 仍高负载 | 需调 max 或优化 |
| 频繁抖动 | 调冷却/阈值 |

## Checklist

- [ ] min ≥ 2 跨 AZ
- [ ] 扩容脚本/镜像预热
- [ ] max 与预算对齐
- [ ] 季度压测更新参数

弹性是云的核心价值，**需自动化而非手工加机器**。
