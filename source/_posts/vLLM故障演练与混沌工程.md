推理故障直接影响对话业务，需在 staging **定期注入故障** 验证告警与 Runbook。

## 演练场景

| 场景 | 操作 | 期望 |
|------|------|------|
| 杀 Pod | delete pod | 就绪副本接流 |
| OOM | 提高并发触顶 | 告警 + 降载 |
| GPU 掉落 | 模拟 device error | 节点污点/迁移 |
| 网关限流 | 打满 RPM | 429 非雪崩 |
| 坏模型卷 | 挂错路径 | 启动失败告警 |
| 切备集群 | DNS 切换 | RTO 达标 |

## 成功标准

- P0 ≤ 5 分钟触达  
- Runbook 可执行  
- 无未文档化手工步骤  
- 数据/密钥无泄露  

## 频率

| 演练 | 周期 |
|------|------|
| 实例故障 | 季 |
| 过载 429 | 季 |
| DR 切流 | 半年 |

## 安全

- 禁止未审批对生产混沌  
- 大模型 TP 演练用 staging 同规格池  

## 反模式

- 只演练「进程还在」不测真实推理
- 演练后不改告警阈值

报告进 **季度 SRE 复盘**。
