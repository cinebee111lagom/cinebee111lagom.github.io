SGLang 是私有化 **LLM 推理与结构化生成控制面**，SRE 目标是保障 **可用性、延迟、吞吐、缓存命中与 GPU 成本** 在 SLA 内长期可运维。

## SRE 职责

| 领域 | 内容 |
|------|------|
| 部署 | 单卡/多卡 TP、Docker、K8s、模型卷 |
| 容量 | 显存、并发、token/s、Radix 缓存 |
| 可观测 | Prometheus、TTFT、缓存命中、GPU |
| 安全 | API Key、网关鉴权、模型与数据隔离 |
| 变更 | 镜像/模型/参数滚动升级 |
| 性能 | batch、量化、前缀共享、结构化解码 |
| 多租户 | 模型分池、配额、限流 |
| 成本 | GPU 利用率、闲置回收 |

## 生产 SLA 参考

| 指标 | 目标（按业务调） |
|------|------------------|
| API 可用性 | 99.9% |
| TTFT P99 | ≤ 2s（7B 短上下文） |
| 端到端 P99 | ≤ 业务约定 |
| 错误率 5xx | < 0.1% |
| 故障发现 | ≤ 5 分钟 |
| 单实例恢复 RTO | ≤ 15 分钟 |

## 架构演进

```
单机 Docker → K8s + PVC 模型
           → LB 多副本（小模型）
           → TP 大模型 + 网关限流
           → 多模型池 + Radix 感知路由
```

## 与算法、平台的边界

- **算法**：模型选型、提示词、结构化 Schema、评测集
- **平台/K8s**：GPU 调度、存储、网络
- **SGLang SRE**：推理服务稳定性、容量、告警、Runbook
