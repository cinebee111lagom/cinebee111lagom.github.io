VPC 是云上网络边界，安全组是实例级防火墙，配置错误是常见事故源。

## VPC 规划

```
Region: cn-hangzhou
VPC: 10.0.0.0/16
├── vSwitch 生产-AZ-h: 10.0.1.0/24
├── vSwitch 生产-AZ-i: 10.0.2.0/24
├── vSwitch 数据库:     10.0.10.0/24（无公网）
└── vSwitch 中间件:     10.0.20.0/24
```

| 原则 | 说明 |
|------|------|
| CIDR 预留余量 | /16 常用 |
| 每 AZ 至少一个 vSwitch | 多 AZ 部署 |
| 数据库子网无 NAT | 仅内网访问 |

## NAT 与公网

```
私网 ECS → NAT 网关 → 公网（出向）
用户 → ALB（公网）→ 私网 ECS（入向）
```

生产 API **走 SLB/ALB**，非 ECS 公网 IP 直连。

## 安全组基线

```
sg-app（应用层）
  入：仅 sg-alb 的 8080
  出：sg-db 3306、sg-redis 6379、0.0.0.0/443

sg-db（数据层）
  入：仅 sg-app 的 3306
  出：拒绝或最小

sg-alb
  入：0.0.0.0/443（或 WAF 回源 IP）
  出：sg-app 8080
```

**安全组引用安全组**，非 CIDR 0.0.0.0/0 到 DB。

## 网络 ACL（可选）

子网级额外防护，默认允许，紧急时可 deny。

## 对等连接 / CEN

跨 VPC、跨 Region 互通用 **云企业网 CEN**，非公网暴露。

## Checklist

- [ ] 无 0.0.0.0/0 到 22/3306/6379
- [ ] RDS 白名单仅应用安全组
- [ ] VPC Flow Log 开启（审计）
- [ ] 网段不与线下冲突（混合云）

网络设计一次做对，**后期改 CIDR 代价极大**。
