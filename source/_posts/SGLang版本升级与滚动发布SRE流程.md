SGLang / CUDA / 驱动 / 模型格式任一不匹配都可能 **起不来或静默掉速**。

## 升级对象

| 组件 | 风险 |
|------|------|
| SGLang 镜像 | API/参数变更、性能回退 |
| CUDA / 驱动 | 兼容性 |
| 模型权重 | 行为与显存变化 |
| 启动参数 | OOM 或吞吐变化 |
| 网关/SDK | 客户端兼容 |

## 发布流程

```
预发压测 → 金丝雀 1 副本
        → 对比 TTFT/错误率/命中率
        → 分批滚动 → 观察窗口
        → 出问题立即回滚镜像+参数
```

## Checklist

- [ ] Release note 已读，破坏性变更已评估  
- [ ] 预发用同卡型、同模型  
- [ ] 回滚镜像 tag 固定可用  
- [ ] 结构化输出黄金用例回归  
- [ ] 监控与告警在升级窗口加强值守  

## 滚动注意

- TP 大模型：滚动单位常是 **整组 GPU**，不是随意拆卡  
- 多副本小模型：可逐 Pod 滚动  
- 前缀缓存：滚动会短暂丢热缓存，预期 TTFT 抖动  

## 反模式

- 生产追 `latest`  
- 无预发直接全量  
- 只回滚镜像不回滚参数

**变更窗口写清：开始时间、批次、回滚负责人。**
