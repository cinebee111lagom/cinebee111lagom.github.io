阿里云灾备靠**多 AZ + 备份 + 跨 Region 复制**组合，需明确 RPO/RTO。

## RDS

| 能力 | RPO |
|------|-----|
| 高可用跨 AZ | 切换分钟级 |
| 自动备份 + binlog | PITR 分钟~小时 |
| 跨 Region 备份 | 异地 |

```
恢复演练：从备份创建克隆实例 → 验证 → 销毁
```

## ECS

```
云盘自动快照策略：每日，保留 7~30 天
自定义镜像：Golden Image 版本化
重要数据：应用层备份到 OSS
```

## OSS

```
版本控制 + 跨 Region 复制（CRR）
MFA Delete（防误删）
```

## ACK

```
etcd 备份（托管版阿里云负责）
PV 快照（云盘 CSI Snapshot）
应用有状态：Velero → OSS
```

## 同城灾备（多 AZ）

```
SLB + 多 AZ ECS + RDS 高可用
单 AZ 故障：自动切换，RTO 分钟级
```

## 异地灾备（跨 Region）

```
RDS 跨 Region 备份 / DTS 同步
OSS CRR
DNS 切换（云解析 GTM）
RTO：小时级（需演练）
```
