## 建议顺序

1. Quickstart → Install → Demo  
2. Learning：data model / api guarantees / glossary  
3. Tasks：developer 读写与 watch/lease  
4. Op-guide：clustering、security、maintenance、monitoring  
5. Tuning + Performance + Metrics  
6. Upgrades（匹配你的版本路径）  
7. Failure / Recovery 演练
