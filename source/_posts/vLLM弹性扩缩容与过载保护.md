GPU 贵且启动慢，扩缩要 **提前量 + 过载保护**，不能照搬 CPU HPA。

## 扩缩信号

| 信号 | 动作 |
|------|------|
| 排队深度持续高 | 扩副本（小模型） |
| TTFT P99 超 SLO | 扩容或降载 |
| GPU util 长期极低 | 缩容 |
| 定时高峰 | 预约扩容 |

## HPA 注意

- 自定义指标：队列、TPM、GPU util  
- **冷却时间** 拉长（模型加载慢）  
- 最大副本受 GPU 库存硬限制  

## 过载保护

```
网关限流 → 429
服务端 max_num_seqs 封顶
排队超时快速失败（避免雪崩）
降级：切小模型 / 关长上下文
```

## 启动慢的对策

| 手段 | 说明 |
|------|------|
| 热备副本 | minReplicas ≥ 1~2 |
| 模型本地盘 | 减少加载时间 |
| 预热请求 | Ready 前跑一条 dummy |

## 批处理与在线隔离

离线评测/蒸馏勿打在线池；单独 batch 池，避免抢占。

## 反模式

- 按 CPU 60% 扩 LLM Pod
- 瞬时打满再扩，用户已超时
- 无 429，让队列无限涨

扩缩策略写进 **容量与 Oncall Runbook**。
