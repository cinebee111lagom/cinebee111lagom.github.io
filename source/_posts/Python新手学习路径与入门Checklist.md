## 推荐学习路径

```
第 1 周：环境 + 语法 + 流程控制
  └─ 篇 1~4

第 2 周：数据结构 + 函数 + 文件/异常
  └─ 篇 5~8

第 3 周：OOP + 标准库 + pip
  └─ 篇 9~11

第 4 周：推导式 + 正则 + requests + pandas
  └─ 篇 12~16

第 5 周：自动化 + 测试 + 小项目
  └─ 篇 17~20
```

## 入门 Checklist

### 基础

- [ ] Python 3.11+ 与 venv 已配置
- [ ] 理解变量、类型、if/for/while
- [ ] 熟练使用 list、dict
- [ ] 会写函数和 import 模块
- [ ] 会用 with 读写文件、try/except

### 进阶

- [ ] 理解 class 与 `__init__`
- [ ] 会用 json、datetime、pathlib
- [ ] pip + requirements.txt
- [ ] 列表推导式
- [ ] requests 调 API

### 实战

- [ ] 完成 1 个自动化脚本（如日志清理）
- [ ] pandas 读 CSV 做简单统计
- [ ] 写 3 个以上 pytest 用例
- [ ] 独立 debug 一个报错
