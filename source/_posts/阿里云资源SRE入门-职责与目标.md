阿里云是企业上云的主流选择，资源 SRE 目标是让云基础设施在**可用性、成本、合规**下长期稳定运行。

## SRE 职责

| 领域 | 内容 |
|------|------|
| 账号治理 | RAM、资源组、Tag、多账号 |
| 计算 | ECS、ACK、弹性伸缩 |
| 网络 | VPC、SLB/ALB、CDN、DNS |
| 存储 | OSS、NAS、云盘 |
| 数据库 | RDS、Redis、PolarDB |
| 可观测 | 云监控、ARMS、日志服务 SLS |
| 安全 | 安全组、WAF、堡垒机、KMS |
| 成本 | 账单、预留实例、FinOps |
| 容灾 | 多 AZ、跨 Region、备份 |

## 生产 SLA 参考

| 指标 | 目标 |
|------|------|
| 核心服务可用性 | 99.95% ~ 99.99% |
| 告警响应 | P0 5 分钟、P1 15 分钟 |
| RPO | ≤ 1h（RDS 备份 + OSS 跨 Region） |
| RTO | ≤ 30min（多 AZ 切换） |
| 成本偏差 | 月度预算 ±10% |

## 架构演进

```
单账号单 Region → 多 AZ 高可用
               → 多账号（生产/测试/安全）
               → ACK + 微服务 + 托管中间件
               → 混合云 / 异地多活
```

## 与开发、平台的边界

- **开发**：应用部署、配置、业务监控
- **SRE/云管**：VPC、ECS、RDS、监控告警、成本、合规
- **安全**：等保、审计、密钥、渗透
