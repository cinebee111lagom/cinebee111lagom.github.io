**Ceph** 是开源的统一分布式存储系统，在 **块（RBD）、文件（CephFS）、对象（RGW）** 三种接口下提供 PB 级软件定义存储。

## Ceph 能做什么

| 接口 | 说明 | 典型用途 |
|------|------|----------|
| RBD | 块设备 | 虚拟机盘、K8s PV |
| CephFS | POSIX 文件系统 | 共享文件、HPC |
| RGW | S3/Swift 兼容对象 | 备份、静态资源、数据湖 |

## 核心优势

| 优势 | 说明 |
|------|------|
| 统一存储 | 一套集群多种接口 |
| 无单点 | 去中心化 RADOS |
| 弹性扩展 | 加 OSD 即可扩容 |
| 自愈 | 自动副本/纠删码恢复 |
| 开源 | 社区版免费 |

## 与商业存储对比

| | Ceph | 传统 SAN/NAS |
|---|------|--------------|
| 成本 | 商用硬件 + 软件免费 | 专有硬件贵 |
| 扩展 | 横向加节点 | 常需换阵列 |
| 运维 | 需专业 SRE | 厂商支持 |
| 性能 | 依赖网络/盘 | 往往更低延迟 |

## 适用场景

**适合**：
- 私有云 / OpenStack / Proxmox VM 盘
- Kubernetes 持久卷（RBD / CephFS）
- 对象存储（S3 兼容）
- 超融合、智算/大数据存储池

**不适合**：
- 极低延迟 OLTP 数据库盘（考虑 NVMe SAN）
- 极小部署（<3 节点难满足冗余）
- 无专职存储运维的小团队（可用云存储）

## 核心组件预览

```
MON（监控）→ OSD（存数据）→ RADOS（核心）
                    ↓
            RBD / CephFS / RGW
```
