云成本是 SRE 持续责任，**FinOps = 可见性 + 优化 + 文化**。

## 成本可见性

```
费用中心 → 按 Tag（project/env/owner）分账
预算管理 → 月度预算 + 告警 80%/100%
资源包/预留实例 → 利用率报表
```

## 优化手段

| 手段 | 适用 |
|------|------|
| 预留实例券 / 节省计划 | 稳定基线 ECS/RDS |
| 按量 Spot | 批处理、CI Agent |
| ESS 夜间缩容 | 潮汐流量 |
| OSS 生命周期 | 冷数据归档 |
| RDS 规格降配 | 长期 CPU < 20% |
| 闲置资源回收 | 无 EIP 绑定、0 流量 SLB |

## 闲置资源巡检

```bash
# 定期脚本/Config 审计
- 7 天 CPU < 5% 的 ECS
- 未挂载云盘
- 空负载 SLB
- 过期快照
```

## 规格 rightsizing

```
1. 云监控看 30 天 CPU/内存 P95
2. 降一档规格（staging 验证）
3. 大促前临时升配
```

## 预算告警

```
项目 payment 月预算 50 万
告警：80% 预警、100% 严重、110% 冻结新建（流程）
```

## 组织文化

- 开发可见自己的 Tag 账单
- 成本 review 纳入 sprint retro
- 「降配/回收」工单流程

## Checklist

- [ ] 100% 资源强制 Tag
- [ ] 月度成本报告
- [ ] 预留券利用率 > 80%
- [ ] 季度闲置资源清理
- [ ] 大促成本预案

**成本优化是持续过程，不是一次性项目**。
