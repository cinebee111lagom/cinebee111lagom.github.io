Python 是一门**简洁、易读**的高级编程语言，适合新手作为第一门语言，也广泛用于生产环境。

## Python 能做什么

| 场景 | 示例 |
|------|------|
| 脚本自动化 | 批量重命名、日志清理、定时任务 |
| Web 开发 | Django、FastAPI 后端 |
| 数据分析 | pandas、Jupyter |
| 机器学习 | PyTorch、scikit-learn |
| 运维/DevOps | Ansible、K8s 客户端 |
| 爬虫 | requests + BeautifulSoup |

## 为什么选择 Python

- **语法简单**：缩进代替大括号，接近自然语言
- **生态丰富**：PyPI 海量第三方库
- **跨平台**：Windows / macOS / Linux
- **社区活跃**：文档、教程、Stack Overflow 资源多

## 与其他语言对比

| 语言 | 特点 |
|------|------|
| C/C++ | 性能高，学习曲线陡 |
| Java | 企业级，语法冗长 |
| **Python** | 开发快，性能中等（CPU 密集可调 C 扩展） |
| JavaScript | 前端必备，后端也可 |

## 适用与不适合

**适合**：
- 编程零基础入门
- 快速原型、脚本工具
- 数据/AI/自动化

**不太适合**：
- 极致性能（游戏引擎核心、高频交易）
- 移动端原生 App（可用 Kivy，但非主流）

## 学习路线预览

```
环境 → 语法 → 数据结构 → 函数 → 文件/异常
     → OOP → 标准库 → 第三方库 → 实战项目
```
