网关是推理集群的 **安全带**：鉴权、限流、路由、熔断。

## 网关职责

| 能力 | 说明 |
|------|------|
| 鉴权 | API Key / JWT |
| 限流 | 按租户 QPS / 并发 / token 预算 |
| 路由 | 按 model 到不同池 |
| 熔断 | 上游错误率过高摘流 |
| 观测 | 统一接入日志与 trace |

## 限流维度

```
租户 → 模型 → 实例池
     → 并发上限
     → 每分钟 token 预算（可选）
```

## 与 SGLang 的配合

- 网关并发 ≤ 后端可承载并发之和  
- 429 语义对客户端清晰（Retry-After）  
- 流式请求超时与空闲超时单独设  

## 流量治理场景

| 场景 | 动作 |
|------|------|
| 大促 | 提高核心租户配额，压非核心 |
| 坏版本 | 网关切回旧池 |
| 单模型过热 | 单独限流，不影响其他 model |

## 反模式

- 限流只做在 SGLang 进程内、无全局视图  
- 无租户维度，一人打满全家  
- 流式超时长到占死连接  

**把「谁可以打爆集群」变成显式配额，而不是拼手速。**
