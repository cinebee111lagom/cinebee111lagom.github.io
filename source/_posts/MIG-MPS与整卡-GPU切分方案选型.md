三种 GPU 使用模式如何选？一张决策表帮你快速判断。

## 对比总览

| 维度 | 整卡 | MIG | MPS |
|------|------|-----|-----|
| 隔离性 | 最强 | 硬件强 | 弱 |
| 灵活性 | 低 | 中（静态 profile） | 高 |
| 配置复杂度 | 低 | 高 | 低 |
| 资源利用率 | 低（小任务浪费） | 高 | 高 |
| 尾延迟 | 稳定 | 稳定 | 波动 |
| 硬件要求 | 任意 | A100/H100 等 | 任意 |

## 选型决策树

```
任务需要 > 40GB 显存？
  ├─ 是 → 整卡 / MIG 7g.80gb
  └─ 否 → 多租户生产环境？
           ├─ 是 → MIG（1g/2g profile）
           └─ 否 → 延迟敏感？
                    ├─ 是 → 整卡或独占 MIG
                    └─ 否 → 开发测试 → MPS
```

## 场景推荐

| 场景 | 推荐 |
|------|------|
| 大模型训练 | 整卡或多卡 |
| 在线推理 SaaS | MIG 1g/2g |
| 视频转码多路 | MIG 1g + NVENC |
| 团队开发机 | MPS |
| 云游戏 | vGPU |

## 混合集群

生产常见架构：

- **训练池**：整卡 A100，Slurm / Volcano 调度
- **推理池**：MIG 切分，K8s Device Plugin
- **开发池**：MPS 共享 T4

按池隔离，避免训练抢占推理资源。

选型没有银弹，**隔离要求 vs 利用率** 是核心权衡。
