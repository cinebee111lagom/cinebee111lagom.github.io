PAT（个人访问令牌）在 **带 Manager** 部署下用于 Open API / 自动化调用鉴权。

## 实践

- 最小权限、定期轮换
- 存入 Secret，禁止写进 Git
- 控制台 Developer 页面可管理令牌

> 官方文档：[Personal Access Tokens](https://d7y.io/docs/next/advanced-guides/personal-access-tokens/)
