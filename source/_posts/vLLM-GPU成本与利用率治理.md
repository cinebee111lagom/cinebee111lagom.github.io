GPU 是 LLM 平台最大成本，SRE 要用 **利用率与单位 token 成本** 说话。

## 成本指标

| 指标 | 含义 |
|------|------|
| GPU 小时 | 占用时长 |
| 有效 token/s | 有用产出 |
| 成本/1M token | 单位经济性 |
| 闲置率 | util 长期过低 |

```
成本/1M token ≈ GPU小时单价 / (token/s × 3600) × 1e6
```

## 治理手段

| 手段 | 效果 |
|------|------|
| 量化 | 同卡更大模型或更高并发 |
| 合理 max_model_len | 提高并发密度 |
| 分时扩缩 | 夜间缩容 |
| 批处理离峰 | 占闲时 |
| 前缀缓存 | 降重复预填 |
| 小模型分流 | 简单请求不占大模型 |

## 闲置处理

```
GPU util P50 < 15% 且持续 7 天
→ 评估缩容 / 合并池 / 释放节点
```

注意保留 **突发余量** 与 SLA。

## Showback

## 反模式

- 为「资源申请方便」长期占满空卡
- 只看卡数不看 token 产出
- 无夜间缩容

成本周报与 **容量周报** 合并评审。
