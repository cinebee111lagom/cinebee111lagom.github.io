Web Console 是 Manager 提供的可视化控制台，用于集群、任务、预热与审计等管理。

## 能力地图

| 模块 | 作用 |
|------|------|
| 登录/注册/用户 | 账号体系 |
| Cluster | 集群管理 |
| Job / Preheat | 预热任务 |
| Resource Task | 任务资源 |
| Persistent Cache Task | 持久缓存任务 |
| Audit / GC | 审计与垃圾回收 |
| Developer PAT | 令牌管理 |

仅 **With Manager** 部署可用。

> 官方文档：[Web Console](https://d7y.io/docs/next/advanced-guides/web-console/)
